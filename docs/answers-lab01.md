# Thảo luận Lab 01

1. git mv ghi nhận thao tác chuyển tệp trong staging. Git nhận diện đổi tên qua độ giống nhau của nội dung; git log --follow giúp theo dõi tệp qua lần di chuyển.

2. release/lab01 là mốc bàn giao đầu tiên. Nhánh có thể tiến thêm khi có bản sửa; tag đánh dấu chính xác một commit.

3. PR lưu mục đích, diff và cách kiểm tra. Kể cả khi làm cá nhân, đó là điểm kiểm soát trước khi thay đổi master.
